# Gurugram Metro Catchment Analysis

This project is a small location-data analysis work sample created for a Research Data Analyst application.

The script collects Rapid Metro Gurugram station names, geocodes the stations using OpenStreetMap's Nominatim service, and calculates their distance from IFFCO Chowk, Gurugram. The final results are saved as a CSV file.

The purpose of this project is to demonstrate a simple research-data workflow:

**Collect → Geocode → Calculate Distance → Export**

### Files

- `gurugram_locality_catchment.py` — Python script used for the analysis
- `gurugram_locality_catchment.csv` — Output dataset

### Tools Used

- Python
- Requests
- BeautifulSoup
- GeoPy
- OpenStreetMap / Nominatim

This is a sample project created to demonstrate practical data collection, basic geospatial analysis, and structured dataset preparation.
